# 08 - Architecture Alignment Discovery

## Scope and prerequisites

This chapter reconstructs documentation-only fictional simulated SES-007. Start from [SES-001–SES-005 records](../discovery/sessions/README.md), preliminary [findings](../discovery/findings/preliminary-findings.md), [risks](../project-management/risk-register.md), and [ADR governance](../architecture/decisions/README.md). Verify clean aligned `main`, ignore/tracking state of the private plan, and identifier maxima first. The private plan was read silently as local context, challenged rather than copied, and never used as public evidence.

## Reconstruction method

1. Prepare the [brief](../discovery/sessions/SES-007-architecture-alignment-discovery/00-session-brief.md) with four scenarios, seven fictional roles, evidence rules, and external-consumer dependency.
2. Simulate the [38-exchange transcript](../discovery/sessions/SES-007-architecture-alignment-discovery/01-simulated-transcript.md) with disagreement, competing options, rejected inference, and owner-assigned requests. Keep analytical IDs outside dialogue.
3. Distinguish observations, candidate directions, tensions, non-decisions, ADR topics, and gaps in the [session record](../discovery/sessions/SES-007-architecture-alignment-discovery/02-session-record.md). Extract attributed statements and preliminary findings with stable IDs.
4. Derive [drivers](../discovery/architecture/architecture-drivers.md) from outcome and constraint evidence; [boundaries](../discovery/architecture/candidate-boundaries.md) from responsibility and failure questions; [alternatives](../discovery/architecture/architecture-alternatives.md) from competing shapes; [ADR candidates](../discovery/architecture/adr-candidates.md) from consequential future choices; and [deferred questions](../discovery/architecture/deferred-decisions.md) from missing evidence. Preserve conflicting evidence, owners, validation, and nonterminal statuses.
5. Propagate only evidence-linked implications to domain, security, reliability, product, risk, governance, and [synthesis](../discovery/11-architecture-alignment-discovery.md) records. [Discovery architecture](../discovery/architecture/README.md) is preliminary analysis; [architecture documentation](../architecture/README.md) remains without a baseline or accepted ADR. SES-006 and I01-P08 remain incomplete.

## Validation and limitations

Run `git diff --check`, status/branch/staging, ignore/tracking checks, Markdown link resolution, ID sequence and reference checks, participant coverage, status/scope language checks, and changed-file inspection. No application test suite applies. The workshop uses fictional simulated evidence only. No partner interview, source record, outage experiment, benchmark, approved requirement, authority charter, technology selection, architecture baseline, ADR, diagram, or implementation is provided.
