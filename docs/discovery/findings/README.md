# Discovery Findings

Findings are analysis derived from cited fictional discovery evidence; they are not stakeholder speech, requirements, or decisions. Use immutable `FND-NNN` identifiers. Each entry must show supporting and limiting evidence, confidence, validation, owner, and status.

Allowed statuses are `Preliminary`, `Under validation`, `Validated`, and `Rejected`. A single simulated session should normally remain preliminary or under validation. Current entries are in the [preliminary finding register](preliminary-findings.md).
