# Current-State Journey Evidence

Journey records describe fictional, preliminary sequences as reported today. They are not target workflows, diagrams, requirements, or commitments.

- [Current API delivery journeys](current-api-delivery-journeys.md)

Use stable `JRN-NNN` IDs and retain variations, conflicts, estimates, and missing evidence. Allowed statuses are `Preliminary`, `Under validation`, `Validated`, and `Rejected`.
