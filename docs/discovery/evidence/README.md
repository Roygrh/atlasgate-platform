# Discovery Evidence

This directory preserves attributed evidence from fictional simulated discovery activities. Evidence is not verified fact, a finding, a requirement, or a decision.

Stakeholder statements use immutable `STMT-NNN` identifiers and retain session, speaker, type, topic, limitations, related uncertainty, and a source anchor. New statements append to the [stakeholder statement register](stakeholder-statements.md); identifiers are never reused or renumbered.
