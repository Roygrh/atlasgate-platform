# Consumer Evidence

Consumer records derive from fictional simulated discovery. A segment groups people or teams with sufficiently similar jobs and constraints for investigation; it is not a finalized persona, market commitment, or approved scope.

- [Preliminary consumer segments](consumer-segments.md)

Use stable `SEG-NNN` IDs. Preserve evidence, differences, validation needs, ownership, and lifecycle status. Allowed statuses are `Preliminary`, `Under validation`, `Validated`, and `Rejected`; validation requires evidence beyond a single simulation.
