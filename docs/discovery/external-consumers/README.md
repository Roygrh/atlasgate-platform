# External-Consumer Discovery Analysis

All records here derive from the fictional, simulated [SES-006 transcript](../sessions/SES-006-external-consumer-discovery/01-simulated-transcript.md). Rachel Kim and Meridian Retail Partners are fictional. One account identifies candidate needs and dependencies; it does not validate prevalence, contractual duty, approved requirement, or mechanism.

| Register | Purpose |
| --- | --- |
| [Consumer needs](consumer-needs.md) | Jobs and readiness needs (`ECN`) |
| [Onboarding dependencies](onboarding-dependencies.md) | Sequenced prerequisites and waiting (`EOD`) |
| [Support and communication](support-and-communication.md) | Routing, incidents, and safe context (`ESC`) |
| [Change and compatibility](change-and-compatibility.md) | Notice, semantic impact, and migration (`ECC`) |
| [Traffic expectations](traffic-expectations.md) | Visibility and diagnosis questions (`ETR`) |

Every record states a transcript source, uncertainty, validation need, owner, and non-terminal status. These are analytical IDs, never dialogue or approved specifications.
