# Discovery Session Index

All sessions are fictional simulations created for the AtlasGate professional portfolio. They do not describe real meetings, organizations, or people.

## Naming and lifecycle

Session IDs use immutable `SES-NNN` identifiers. Directories use `SES-NNN-short-title`; files within a session use ordered names. A session moves from `Planned` to `Simulated`, then to `Recorded` after its transcript, record, and evidence links are checked. `Recorded` means documented, not that its claims are validated.

Each session should contain a brief, a clearly labeled simulated transcript, and a session record. Evidence must preserve attribution and source context. Later analysis belongs in registers outside the dialogue; disagreement, uncertainty, and limitations must remain visible.
